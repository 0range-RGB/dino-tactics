# 白垩纪战术 · Cretaceous Tactics

一个 **10 × 10 回合制策略棋盘游戏**，支持人机对战、双人同屏，以及**联网房间对战**。两支恐龙军团在方格盆地中轮流行动，利用容量、朝向、技能冷却与异常状态消灭对手。

## 运行

需要 Node.js 18+。

    npm install
    npm start

浏览器打开：

    http://127.0.0.1:4173

也可以直接双击 index.html 游玩人机/双人同屏；联网模式必须通过服务器启动。

### 局域网访问

    $env:HOST="0.0.0.0"
    npm start

然后让同 Wi-Fi 的朋友访问：

    http://你的局域网IP:4173

## 联网对战

1. 开始界面选择「联网对战」。
2. 输入昵称，创建房间，得到 5 位房间码。
3. 把房间码或「邀请链接」发给朋友；对方打开链接、输入昵称即可加入。
4. 双方各自编辑阵容并点击「准备」。
5. 双方准备后进入布阵阶段；各自摆好位置并点击「布阵完成」/「开始战斗」，蓝方先手。

联网模式特性：

- **服务器权威**：移动、攻击、技能、随机判定全部由 Node 服务器计算，客户端只负责显示和发送指令。
- **房间邀请链接**：复制形如 http://你的域名/?room=ABCDE 的链接，朋友打开后会自动填入房间码。
- **断线重连**：刷新或短暂断网后可用当前标签页的会话恢复；90 秒未重连判负。
- **标签页隔离**：联网会话保存在 sessionStorage，同浏览器双标签不会互相顶号；只有带 `?room=` 的邀请链接会自动打开大厅，旧会话不会劫持首页。
- **布阵保密**：联网布阵阶段不会向对手发送真实坐标、朝向或布阵移动事件；对手队伍栏显示“正在布阵”，开战后公开。 
- **实时同步**：任意一方行动后，双方棋盘、血量、护甲、技能冷却和战报同步更新。
- **移动端**：小屏开始按钮位于阵容编辑器之后；可一键放大棋盘并拖动查看，缩放设置会记住；阵容 +/− 按钮为 44px 触摸目标。
- **房间内阵容编辑**：双方容量上限均为 6，准备前可自由修改。
- **再来一局**：对局结束后双方各自确认再战，单方请求会显示等待状态；30 秒未达成则请求失效，可重新发起。双方同意后返回同一房间。
- **离开房间**：大厅离开会释放房间；布阵阶段离开会关闭房间并通知对手返回联网大厅（有二次确认）；战斗阶段离开立即判负。

> 房间数据保存在服务器内存中，服务器重启后房间会清空。正式运营建议使用常驻 Node 服务。

## 已实现规则

- **10 × 10 棋盘**，上下半场分属苍林盟约与赤焰部族。
- **队伍容量 6**：中型恐龙占 2 格棋盘 / 2 容量，霸王龙占 4 格 / 4 容量，小型恐龙占 1 格 / 1 容量；允许重复编入同种恐龙。
- **六只恐龙**：三角龙、霸王龙、勒苏维斯龙、剑龙、甲龙、伶盗龙。
- **开局布阵**：进入战斗前，双方可在各自半场自由放置恐龙并调整朝向，不消耗行动力。
- 每只恐龙拥有生命、护甲、攻击、行动力、主动技能和被动。
- 行动力即移动步数；移动后可攻击或发动技能，也可以原地行动。
- 攻击范围为自身占格外围一圈的相邻方格；攻击或结束行动后该单位本回合结束。
- 主动技能开局进入冷却；冷却按完整回合计算。
- 三角龙「防御反击」、霸王龙「突袭」、勒苏维斯龙「侧刺反击」、剑龙「尾刃鞭刺」、甲龙「尾槌重击」、伶盗龙「镰锯扑钩」。霸王龙护甲为 2；突袭获得 +2 行动力，并使下一次攻击伤害 +1。
- 甲龙尾槌：2/3 命中，造成 3 点伤害；未破甲追加 2 点护甲伤害，破甲追加 1 点生命伤害，另有 50% 概率压制目标。
- 伶盗龙「镰锯扑钩」：对朝向一格内敌人施加受钩挂，并进入钩挂。小型最多 2 层、中型最多 3 层；大型立即弹开，来源受 3 点伤害、目标受 1 点伤害并后退一格（无法后退时额外受 1 点）。
- 钩挂期间：伶盗龙攻击 +2、无法移动、技能不充能；目标移动时伶盗龙跟随，目标失去受钩挂时钩挂结束。持续 1 回合后可手动解除，3 回合后自动解除。
- 受钩挂：行动力 ≥2 的单位行动力 -1，不能攻击施加者；获得「摆脱」，小型成功率 25%–45%、中型 45%–75%，成功失去一层，若失去最后一层则对施加者造成 2 点伤害。
- 伶盗龙「脆弱之爪」：攻击对护甲只造成 50% 伤害。
- 希腊方阵、温血供应/吞食、甲壳壁垒等被动自动触发。
- 击杀恢复目标最大生命的 1/4（小数取 0.5）；霸王龙可改为吞食。
- 回合结束全体恢复 1 点护甲；连续 3 回合未受攻击伤害恢复 1 点生命。
- 从第 15 回合起，所有存活单位每回合结束时失去 1 点生命（无视护甲）。
- 流血最多 2 层，4 回合后造成 1 点无视护甲伤害；连续 3 回合未受攻击伤害会消退 1 层。
- 除流血外，伤害先扣护甲再扣生命。
- 消灭敌方全部恐龙获胜；双方同时全灭为平局。

## 操作

- 开局布阵：点击己方恐龙，再点高亮格预览**整只恐龙的落位**，确认后放置；可调整朝向。
- 战斗阶段：点击己方恐龙，再点击**虚线落点框内任意格**，整只恐龙会按占格整体平移。
- 相邻敌人会以**红色高亮**，点击敌人即可攻击。
- 右侧行动面板可以发动技能、调整朝向（恐龙图标与朝向箭头同步旋转）、结束该单位或结束回合。
- 甲龙的尾槌会进入目标选择模式，点击紫色高亮敌人释放。
- 按 E 结束当前回合，按 Esc 取消技能选择。
- 联网模式下，只有轮到你时才能操作；对手行动会实时同步。

## 规则裁定

原始规则中未明确的部分采用如下裁定：

1. 小型恐龙占 1×1 格；中型恐龙占 2 格长条，沿朝向前后排列；大型恐龙占 2×2 共 4 格。队伍容量等于队伍总占格数。
2. 一个“回合”指双方各行动一次的大回合；护甲恢复、流血结算、自然恢复在回合末统一处理。
3. 转向不消耗行动力，可在攻击/技能前自由调整；正面为所朝方向 ±45° 的扇形。
4. 剑龙的行动力为 2；开启尾刃鞭刺后仍可移动和攻击。
5. 甲龙护甲为 5；护甲存在时受到的伤害减少 15%，按四舍五入取整。
6. 三角龙方阵要求同队、同朝向、同一行/列相邻；同一只只计一次，敌方不参与。来自正面扇形的伤害减少“数量”，最多 5 点。
7. 流血击杀的恢复奖励归施加流血者；霸王龙通过流血远程击杀时使用普通恢复。
8. 尾槌压制持续到目标下一次行动结束。
9. 甲龙被致命伤害击败的那一次攻击不会触发反伤。
10. 霸王龙吞食大型猎物需要 3 回合（与容量 4 区分）。
11. 移动时恐龙的全部占格作为整体前后左右平移，不拆分；平移不改变朝向，转向仍单独操作；碰撞按完整占位判断。
12. 从第 15 回合起，每回合结束所有存活单位失去 1 点生命；该伤害无视护甲，不触发防御、反伤或击杀恢复。

## 部署

联网模式需要一个能运行 Node.js 常驻进程并支持 WebSocket 的平台。纯静态托管（Cloudflare Pages、GitHub Pages 等）只能玩人机/双人同屏，不能运行联网房间。

Render 免费版完整部署步骤见 [RENDER_DEPLOY.md](RENDER_DEPLOY.md)。

### Render / Railway / Fly.io

1. 把整个项目（不含 node_modules）上传到 Git 仓库。
2. 新建 Node Web Service。
3. Build Command：npm install
4. Start Command：npm start
5. 环境变量：HOST=0.0.0.0
6. 平台会自动注入 PORT。

项目包含 render.yaml，可直接在 Render 创建 Blueprint。

### Docker

    docker build -t dino-tactics .
    docker run -p 8080:8080 dino-tactics

然后访问 http://localhost:8080。

### 静态文件白名单

静态服务器只允许访问浏览器运行所需的四个文件：`/`、`/index.html`、`/app.js`、`/engine.js`、`/styles.css`。

`/server.js`、`/package.json`、`/tests/*`、`/node_modules/*`、`/README.md`、`.env`、日志、数据库文件等默认返回 **404**。仅支持 `GET` / `HEAD`，其余方法返回 `405`。

### 环境变量

    PORT   监听端口，默认 4173
    HOST   监听地址，默认 127.0.0.1；容器/云平台请设为 0.0.0.0

## 技术说明

- 客户端零依赖：原生 HTML / CSS / JavaScript，图形全部由内联 SVG 与 CSS 绘制。
- 服务端仅依赖 ws，使用 Node 原生 http + WebSocket。
- 服务端权威判定，防止客户端篡改行动与随机结果。
- 含合成音效、伤害飘字、屏幕震动与减少动画偏好支持。
- 桌面端按 1366×768 与 1440×1000 验证；移动端为单列布局，行动面板紧贴棋盘下方。
